# Review Intelligence System

A machine learning and AI-powered application designed to analyze customer reviews from different apps and platforms. The system aims to help businesses understand customer sentiment, emotions, and feedback through a unified review analysis platform.

**ShopMood** is the demo customer application developed to demonstrate the system's capabilities.

## Features
- Review sentiment and emotion analysis
- Customer feedback insights
- AI-powered review chatbot
- CSV review upload and analysis
- Integration with multiple platforms (planned)

## Technologies Used
- Python, Flask
- HTML, CSS, JavaScript
- Scikit-learn, Pandas, NumPy
- SQLite, Flask-SQLAlchemy

## Installation
1. Clone or download the repository.
2. Create and activate a virtual environment.
3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Configure the required environment variables in `.env`.
5. Run the application:

   ```bash
   flask --app backend.app:create_app run --debug
   ```

## Project Goal
To develop a unified review analysis platform that can connect with different applications and transform customer feedback into actionable insights.
